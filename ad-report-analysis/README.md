# 亚马逊广告数据分析与机器学习预测
> 项目定位：跨境B2C亚马逊运营辅助脚本 + 机器学习入门实践。从数据清洗、广告指标计算，到训练回归/分类模型预测广告表现，完整走通机器学习基础流程。基于模拟广告数据集验证，作为自学 AI 的产出记录。

## 项目背景
亚马逊运营日常需下载广告后台CSV报表，手动在Excel计算ACoS、CTR、CVR，重复且耗时。本项目先用脚本一键清洗、计算指标；进一步训练机器学习模型预测广告表现，用数据辅助广告优化决策。

## 功能一：广告报表数据分析（Python / pandas）
1. 读取广告CSV原始报表
2. 数据清洗：去除空行、过滤无效曝光/零销售额记录
3. 自动计算核心指标：
   - CTR = 点击量 / 曝光量
   - CVR = 订单数 / 点击量
   - ACoS = 广告花费 / 广告销售额
4. 输出广告组汇总结果，筛选高ACoS低效广告

## 功能二：机器学习预测（Python / scikit-learn）
1. **数据生成** `make_ad_data.py`：按固定随机种子模拟100条广告数据，含高/低转化两组不同规律
2. **回归：预测 ACoS** `predict_ac.py`：线性回归，用曝光/点击/花费/订单/CTR 预测 ACoS，用 R² / MAE 评估
3. **分类：预测广告是否盈利** `predict_ac.py`：逻辑回归，预测 is_profit（ACoS<0.5 记为盈利），用准确率评估
4. **评估与诊断** `calc_ac.py`：数据清洗、指标计算、模型系数与相关性诊断

## 机器学习学习记录（自学产出）
- **回归 vs 分类**：回归预测连续数值（ACoS 是多少），分类预测离散类别（盈不盈利）；分类用准确率、回归用 R²/MAE 评估
- **特征与目标**：X=特征（输入）、y=目标（要预测的答案）；数据拆分为训练/测试集验证模型真实能力
- **模型拟合**：`model.fit()` 自动算出最优系数，`model.predict()` 对新数据预测
- **多重共线性**：Clicks/Spend/Orders 高度相关（相关系数≈0.9），导致单个系数失真甚至符号反转；用相关性矩阵 `df.corr()` 诊断
- **特征选择**：删掉冗余特征后，系数恢复可解释性（CTR 系数从 +4.2 恢复为 -25.6）
- **评估基线**：分类要对比"无脑猜多数类"的基线准确率；数据类别不平衡时准确率会误导
- **特征泄漏**：用能推出答案的特征（Clicks/Spend/Orders → ACoS → is_profit）会虚高准确率（47%→94%），需沿"特征→标签"因果链排查

## 技术栈
Python, pandas, scikit-learn, matplotlib（数据均为本地模拟，不调用亚马逊API，仅用于学习）

## 运行方法
1. 运行 `make_ad_data.py` 生成模拟数据 `ad_data_100.csv`
2. 运行 `calc_ac.py` 做数据清洗与指标计算
3. 运行 `predict_ac.py` 训练回归/分类模型，输出评估指标
