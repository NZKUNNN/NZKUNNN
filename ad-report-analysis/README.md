# 亚马逊广告数据分析与机器学习预测
> 项目定位：跨境B2C亚马逊运营辅助脚本 + 机器学习入门实践。从数据清洗、广告指标计算，到训练回归/分类模型预测广告表现，完整走通机器学习基础流程。基于模拟广告数据集验证，作为自学 AI 的产出记录。

## 项目背景
亚马逊运营日常需下载广告后台CSV报表，手动在Excel计算ACoS、CTR、CVR，重复且耗时。本项目先用脚本一键清洗、计算指标；进一步训练机器学习模型预测广告表现，用数据辅助广告优化决策。

## 功能一：广告报表数据分析（Python / pandas）
1. 读取广告CSV原始报表
2. 数据清洗：去除空行、过滤无效曝光/零销售额记录
3. 自动计算核心指标：
   - CTR = 点击量 / 曝光量
   - CVR = 订单数 / 点击量
   - ACoS = 广告花费 / 广告销售额
4. 输出广告组汇总结果，筛选高ACoS低效广告

## 功能二：机器学习预测（Python / scikit-learn）
1. **数据生成** `make_ad_data.py`：按固定随机种子模拟100条广告数据，含高/低转化两组不同规律
2. **回归：预测 ACoS** `predict_acos.py`：线性回归，用曝光/点击/花费/订单/CTR 预测 ACoS，用 R² / MAE 评估，含系数解读与共线性诊断
3. **分类：预测广告是否盈利** `classify_profit.py`：逻辑回归，预测 is_profit（ACoS<0.5 记为盈利），用准确率评估，含基线对比与防特征泄漏说明
4. **评估与诊断** `calc_ac.py`：数据清洗、指标计算、模型系数与相关性诊断
5. **交叉验证评估** `cv_demo.py`：用五折交叉验证（cv=5）评估线性回归真实水平，输出 5 个分数、平均分与标准差，抹平单次切分运气
6. **非线性模型实验** `tree_demo.py` / `forest_demo.py`：用决策树、随机森林预测 ACoS，与线性回归交叉验证对比，展示非线性学习能力与随机森林对过拟合的治理

## 机器学习学习记录（自学产出）
- **回归 vs 分类**：回归预测连续数值（ACoS 是多少），分类预测离散类别（盈不盈利）；分类用准确率、回归用 R²/MAE 评估
- **特征与目标**：X=特征（输入）、y=目标（要预测的答案）；数据拆分为训练/测试集验证模型真实能力
- **模型拟合**：`model.fit()` 自动算出最优系数，`model.predict()` 对新数据预测
- **多重共线性**：Clicks/Spend/Orders 高度相关（相关系数≈0.9），导致单个系数失真甚至符号反转；用相关性矩阵 `df.corr()` 诊断
- **特征选择**：删掉冗余特征后，系数恢复可解释性（CTR 系数从 +4.2 恢复为 -25.6）
- **评估基线**：分类要对比"无脑猜多数类"的基线准确率；数据类别不平衡时准确率会误导
- **特征泄漏**：用能推出答案的特征（Clicks/Spend/Orders → ACoS → is_profit）会虚高准确率（47%→94%），需沿"特征→标签"因果链排查
- **K折交叉验证** `cv_demo.py`：单次切分 train_test_split 靠运气（5折分数从0.21晃到0.58，差近3倍）；K折交叉验证切K份、轮流测K次取平均，评估更稳。数据少则折数要少（30行用 cv=5 比 cv=10 稳）
- **R² vs 准确率**：回归预测连续值用 R²（比"瞎猜平均值"缩小了多少误差，0.429=缩小42.9%），分类预测离散类别用准确率（猜对比例）。R²=0.98 但交叉验证0.30=过拟合信号
- **线性模型学不了非线性**：ACoS=Spend/Sales 是除法（非线性），线性回归只能做线性组合、学不了除法；人工构造 `spend_div_sales` 特征后 R² 从0.52飙到1.0 → 特征工程=把非线性"翻译"成特征
- **特征泄漏4次对照实验**：干净特征0.429（诚实）/+Clicks 0.440（间接泄漏）/+Spend&Sales 0.522（直接泄漏，但线性学不了除法）/ +人工除法特征1.0（答案本体）。交叉验证治不了泄漏（每折都有作弊特征），泄漏靠业务理解+特征选择
- **过拟合 vs 欠拟合**：过拟合=模型太复杂、把噪声也背了（训练高、验证低）；欠拟合=模型太简单、规律没学到（训练验证都差）。交叉验证能识破过拟合，但治不了特征泄漏（一个是模型问题，一个是数据问题）
- **决策树** `tree_demo.py`：不断提问、把数据切成一块块区域，能学线性模型学不了的**非线性**（ACoS 除法）；交叉验证平均 R² 从线性 0.429 提升到 0.586，但单棵树切太细易过拟合（标准差 0.195，分数从 0.37 晃到 0.89）
- **随机森林** `forest_demo.py`：多棵树随机采样+随机选特征、投票取平均；既保留非线性能力，又靠"各错各的、平均就对"压住波动、治过拟合，R² 进一步提升到 0.642（标准差从单棵 0.195 回落到 0.163）
- **三模型权衡规律**：线性回归简单稳但学不了非线性 / 单棵决策树能学非线性但易过拟合 / 随机森林综合最优=主流默认模型。sklearn 接口统一（fit/predict），换一行即可对比，但底层是三套完全不同的算法——会"点菜"（换函数）是起点，懂"后厨"（原理/调参/诊断）才能解决真实问题

## 技术栈
Python, pandas, scikit-learn, matplotlib（数据均为本地模拟，不调用亚马逊API，仅用于学习）

## 运行方法
1. 运行 `make_ad_data.py` 生成模拟数据 `ad_data_100.csv`
2. 运行 `calc_ac.py` 做数据清洗与指标计算
3. 运行 `predict_ac.py` 训练回归/分类模型，输出评估指标
