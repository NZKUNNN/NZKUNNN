③ 特征：干净 vs 泄漏
✓ 干净（Impressions·CTR）弱相关 → 可信
✗ 泄漏（Clicks·Spend）相关0.9 → 虚高1.0
特征越干净，越能反映真实预测力
④ 拆数据：本质=test锁死
train 训练 · val 调参 · test 验收
test 锁死，最后只评一次
val 可固定，也可用交叉验证承担
⑤ 选模型：要「试」
从简单到复杂试：
线性 → 决策树 → 随机森林
看哪个在测试集上泛化好
（这是唯一要小范围试的）
⑤ 调参：可叠加
手动改 / GridSearchCV / 正则化
树模型 → 限制 max_depth
线性过拟合 → 才用正则化
不是三选一，可叠加
⑥ 评估：三档 + seed旋钮
单次评估 → 固定seed，像抽奖
交叉验证 → 轮流，省数据
重复评估 → 换seed，看波动
seed 跟着评估走，不是独立选项
⑥ 指标：R² vs MAE
R² → 比瞎猜好了多少
MAE → 平均错多远
一个看提升，一个看误差
✓ 该判断（按数据定，不搜）
评估方式（数据少→交叉验证）
