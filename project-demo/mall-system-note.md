# 开源商城后台业务模块学习笔记（运营视角）
> 学习目标：从运营角度理解电商后台完整业务流转，不深入底层代码，重点看懂运营侧功能模块。
参考项目：macrozheng/mall、newbee-ltd/newbee-mall

## 1. 商品模块
类目管理、SKU维护、商品上下架、图片素材、规格参数、成色/属性标签。
运营关注点：上架商品需要填写哪些字段，SKU拆分逻辑，库存与商品绑定关系。

## 2. 库存模块
库存数量、库存锁定（下单预占库存）、库存预警、仓库调拨。
运营关注点：防止超卖、库存水位监控、备货规划。

## 3. 订单模块
订单创建、状态流转（待付款→待发货→已发货→已完成/售后退款），订单拆单。
运营关注点：订单状态监控，异常订单拦截，履约时效管控。

## 4. 营销模块
优惠券、限时秒杀、活动价格配置、满减活动。
运营关注点：活动规则配置，活动预算与毛利测算，避免亏损。

## 5. 会员/售后模块
会员信息、售后申请、退货退款、纠纷仲裁。
运营关注点：售后权责划分，降低纠纷率，维护店铺账户健康。

## 学习总结
通过研读开源商城后台文档，完整理解电商平台从商品上架、营销活动、订单履约到售后的全链路业务流程，建立运营的全局业务思维，便于在亚马逊运营工作中理解Listing、库存、订单、评价之间的联动关系。
