# 电商转化漏斗 & RFM用户分层分析复盘
## 一、电商转化漏斗（B2C跨境适用）
完整链路：访客 → 点击浏览Listing → 加购 → 下单 → 付款 → 复购
核心指标：
1. 曝光→点击：CTR点击率，受主图、标题、价格影响
2. 点击→加购：加购率，由五点描述、评价、QA、价格决定
3. 加购→下单：下单转化率，库存、运费、优惠券、竞品价格影响
4. 售后环节：退款率、差评率，直接影响Listing权重

漏斗分析思路：定位流失节点，针对性优化。
例：高点击、低加购 → 优化五点描述、评价；高加购低下单 → 检查价格、运费、库存。

## 二、RFM用户分层模型（用户运营）
R：Recency最近一次消费时间
F：Frequency消费频次
M：Monetary消费金额

分层：
- 重要价值用户：最近购买、频次高、消费高，重点维护，促进持续复购
- 重要流失用户：过去消费高，很久未下单，做召回、优惠触达
- 潜力新用户：近期下单，金额不高，引导二次购买
- 低价值用户：低频低客单，减少营销资源投入

## 学习总结
跨境B2C亚马逊运营，漏斗用来优化单品转化；RFM模型用于用户生命周期管理，适合做复购、老客维护。
