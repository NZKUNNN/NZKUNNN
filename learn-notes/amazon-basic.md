# 亚马逊平台基础学习笔记
## 1. Listing核心构成
标题、五点描述、产品详情、主图、A+页面、关键词埋词、类目选择。
Listing核心目标：满足A9算法收录，同时提升买家点击率、转化率。

## 2. A9算法核心逻辑
A9是亚马逊搜索排名算法，核心看3类维度：
1. 相关性：关键词与Listing匹配度、类目匹配
2. 转化能力：CVR、订单量、评价、点击率CTR
3. 账户权重：账户健康、绩效指标、违规记录、库存稳定性

## 3. FBA 库存管理要点
- FBA：亚马逊仓储配送，平台负责仓储、打包、尾程派送、售后
- 重点关注：库存周转、仓储费、超量库存产生长期仓储费、断货风险
- 库存规划：结合销量预测，控制备货量，平衡缺货与仓储成本

## 4. 账户健康指标
ODR订单缺陷率、迟发率、取消率、有效追踪率，是亚马逊账户安全红线。一旦超标会触发审核、限制流量甚至封店。

## 5. 竞品调研思路
1. 筛选同类目竞品，统计核心关键词、价格区间、评价数量、评分
2. 分析Listing图文卖点、差评痛点，挖掘产品差异化机会
3. 监控竞品价格、促销活动、BSR排名变化，判断市场竞争强度
