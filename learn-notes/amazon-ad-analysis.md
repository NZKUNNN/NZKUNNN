# 亚马逊广告学习与报表分析笔记
> 学习目标：看懂广告报表，通过数据调整广告策略，控制ACoS，提升自然权重

## 核心指标
- CTR点击率 = 点击量 / 曝光量：反映主图、标题、价格吸引力
- CVR转化率 = 订单数 / 点击量：产品、评价、价格是否打动买家
- ACoS广告销售成本 = 广告花费 / 广告销售额；ACoS越低，广告投产越好
- 广告花费、广告销售额、自然订单、广告订单

## 广告类型基础
1. Sponsored Products 商品推广：关键词投放，测款、提升关键词排名
2. Sponsored Brands品牌推广：品牌广告，打造品牌认知，适合有品牌店铺
3. Sponsored Display展示型广告：针对浏览过商品的访客做再营销

## 广告复盘思路（运营日常工作）
1. 筛选高花费、低转化关键词，否定无效词，减少浪费
2. 对高转化、低ACoS关键词，提高预算、加价，放大流量
3. 结合自然排名变化，判断广告是否带动自然流量增长
4. 区分：广告带来的订单，是否积累权重，助力自然Listing排名提升

## 自动化分析学习思路
自学Python基础，学习读取广告报表，清洗数据，自动计算ACoS、CTR、CVR，批量筛选低效关键词，辅助运营快速做广告复盘。
> 说明：仅做运营数据分析工具，不开发平台底层功能。
